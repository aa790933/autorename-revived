Rename documents in seconds

Reads PDF, DOCX, XLSX, PPTX, TXT and images. Text extraction runs locally; vision AI is only used when the text layer is poor.

Native

Rust + Tauri Backend

One EXE, no installer needed. Settings travel with the file.

Multi-Provider LLM

Gemini, OpenAI, Anthropic, Ollama, xAI, Custom.

Vision

Vision Mode

Scanned pages with no text layer go to a vision model. Text quality decides automatically.

i18n

Internationalization

English, French, Arabic. Arabic flips the layout to right-to-left.

Safety

Undo & Dry Run

Dry Run shows every new name first. Undo reverses a batch, one click.

What a rename looks like

The template {date}_{doctype}_{company}_{subject} turns a scanner default into a name you can find later.

scan_001.pdf
↓
20240115_Invoice_AcmeCorp_Q3_Report_01.pdf

Placeholders: {date} {company} {doctype} {subject} {original} {sequence} {separator}

Quick start

Grab a release build, or compile it yourself: Rust toolchain, Node.js 20+, pnpm 9.

cd gui && pnpm install
pnpm run build:tauri
→ AutoRename-Revived.exe + portable .zip
